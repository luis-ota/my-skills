# landing-page-analysis

An [OpenCode](https://opencode.ai/) skill for analyzing landing pages focusing on conversion factors before design.

## What it does

- Forces evaluation of fundamentals: traffic source, ICP, value proposition, objections, friction.
- Prevents blind redesigns of pages that were never going to convert.
- Provides a structured checklist and decision tree for LP audits.
- Returns a clear status: `ready-for-design`, `needs-fix`, or `rebuild-needed`.

## Files

| File | Description |
|------|-------------|
| `SKILL.md` | OpenCode skill instructions and decision tree. |
| `README.md` | This file. |

## Usage

This skill is loaded automatically by OpenCode when analyzing a landing page. No installation required.
