# my-skills

A collection of custom [OpenCode](https://opencode.ai/) skills.

## Skills

- [`playwright_frontend_tester`](./playwright_frontend_tester) - Use Playwright to test web apps and fix frontend bugs.
- [`landing_page_analysis`](./landing_page_analysis) - Analyze landing pages focusing on conversion factors before design.

## Installation

Each skill can be installed by symlinking or copying its directory into `~/.config/opencode/skills/`.
